# NASA Mission Task Tracker

## Project Idea

The NASA Mission Task Tracker is a simple web-based tool designed to help NASA mission teams organize and monitor tasks related to a space mission.

The tool allows users to:
- Add mission-related tasks
- View existing tasks
- Mark tasks as completed

The goal of the project is to provide a simple way to organize mission activities while demonstrating basic software engineering and project management practices.

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub

## How to Run or Use the Project

1. Open the `index.html` file in a web browser.
2. Enter a mission task in the input box.
3. Click **Add Task** to add the task.
4. Click **Complete** when a task is finished.

## Project Management

GitHub was used to manage the project through Issues, branches, commits, and pull requests.

Five GitHub Issues were created to plan the project tasks. Development was completed using two feature branches, each containing multiple commits and merged into the main branch through pull requests.

## Future Improvements

If the project were developed further, it could include task priorities, deadlines, mission categories, and data storage.
